# shots/ — Plans individuels bruts (avant montage)

Chaque plan de `docs/mon-histoire-shot-list.md` est généré ou tourné
séparément, puis déposé ici sous son nom exact avant d'être assemblé en
montage final dans `../master/` :

```
shot-001.mp4
shot-002.mp4
shot-003.mp4
...
shot-023.mp4
```

Un sous-dossier `9x16/` peut être ajouté si une version verticale distincte
de certains plans est générée séparément (recommandé plutôt qu'un simple
recadrage automatique — voir la fiche de chaque plan pour son cadrage
vertical prévu) :

```
shots/9x16/shot-001.mp4
shots/9x16/shot-002.mp4
...
```

Ce dossier est un espace de travail de production — son contenu n'est
jamais lu directement par le site (seul `../master/` l'est).
