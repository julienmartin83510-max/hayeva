# posters/ — Image d'affiche (poster)

| Fichier attendu | Format |
|---|---|
| `mon-histoire-poster.jpg` | JPG, 1920×1080, < 300 Ko, compressé pour le web |

C'est la première image visible avant que le visiteur ne lance la lecture
(attribut `poster` du lecteur `<video>`) — elle doit donc être un plan fort
du film (voir `docs/mon-histoire-shot-list.md`, par exemple une image tirée
du SHOT 022 ou 023), jamais une image générique.
