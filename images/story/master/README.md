# master/ — Fichiers vidéo finaux (montage complet)

Déposer ici les deux versions montées du film complet, une fois le montage
final terminé (voir `docs/mon-histoire-shot-list.md` pour la liste des plans
à générer/tourner puis assembler) :

| Fichier attendu | Ratio | Durée cible |
|---|---|---|
| `mon-histoire-16x9.mp4` | 16:9 | ~2:00–2:20 |
| `mon-histoire-9x16.mp4` | 9:16 (recadré dès la conception, jamais un simple crop du 16:9) | ~2:00–2:20 |

Format : MP4, codec H.264, taille raisonnable (le site est optimisé pour la
performance — éviter un fichier de plusieurs centaines de Mo).

Le lecteur du site (`index.html`, overlay `#storyVideoOverlay`) choisit
automatiquement l'un ou l'autre selon la largeur d'écran de la visiteuse ou
du visiteur — aucune autre configuration nécessaire une fois les fichiers
déposés ici sous ces noms exacts.
